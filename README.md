# Lab2
Учебная лабораторная работа: демонстрация и исправление двух уязвимостей из OWASP Top 10 на Python-приложении.
Это намеренно уязвимое приложение. Оно предназначено только для запуска на 127.0.0.1 в учебной среде. См. DISCLAIMER.md
Использованные уязвимости:
1) A03 Injection - SQLi через конкатенацию строк в `/login`
2) A07 Identification & Auth Failures - Пароли в открытом виде + нет rate limit
